✨ Описание проекта

🏙 КРСТ — это демонстрационный проект на React.js, созданный для визуализации идей возможной реинкарнации общественного пространства.

Цель проекта — не предложить готовое решение, а показать как могло бы выглядеть общественное пространство после обновления:

🪑 новые зоны отдыха

🍴 примеры точек притяжения (кафе, рестораны, культурные места)

🏘 альтернативные сценарии использования общественного пространства


Проект носит концептуальный характер и служит вдохновением для обсуждения будущего городских пространств.
